# push-npm-to-pulp pipeline

Release npm OCI snapshot Components to a pulp-backed npm registry without closure-index updates or Errata advisory creation. Each image in a Component is expected to be an OCI artifact containing npm .tgz packages under the artifact root. Package attestation OCI digests are produced when pulp.complianceImagePrefix (or attestation prefix) is set; set pulp.requireAttestations to "true" to fail closed when signing material or .att files are missing (recommended for remediations). pulp.allowContentReplace (default false) replaces same name@version on sha256 mismatch via targeted orphan cleanup. extract-npm-artifacts trustedProvenanceNamespaces is the Snapshot namespace (collect-data.snapshotNamespace).
